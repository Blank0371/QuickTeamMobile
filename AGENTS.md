# Version documentation

Any request that changes the app **must** be documented in `Version.md` under the current in-development version header, with a new version number `1.Y.X`:
- **X** (patch) — increment once per documented change.
- **Y** (build) — increment every time the app is built (new EAS build); reset X to 0 and open a new header.
- **1** (major) — only bumped on a MAJOR update.

Add the entry as part of making the change, not as a separate step.
